Canal de denúncia anônima

Registre uma denúncia sem se identificar. Você receberá um número de protocolo para acompanhamento. Em caso de perigo imediato, ligue sempre 190.

Este é um protótipo demonstrativo. Os dados não são enviados a nenhum servidor e servem apenas para simular o fluxo de denúncia.
